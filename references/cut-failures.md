# SolidWorks 切除失败排查

`FeatureCut4` 返回空值只表示当前草图无法生成这个切除。即使前面的切除成功，也不能据此断定 SolidWorks 版本有问题。记录中的 `operation 2` 是从零开始的第三个操作。

1. 打开 `模型/检查结果.json`，读取 `last_operation` 的名称、轴向、面、切深、轮廓点数和被选面的实际范围；对照 `模型/建模方案.json` 中相应的 `operations[2]`。保留原方案与原始 STL，以便重现。
   若名称为 `X_plus_outline_2`，而 `axis=2, side=-1` 且轮廓位于 `Z=0`，名称对应的 X 正视图与实际 Z 负面冲突。先确认源视图，再检查整批坐标。只改 `axis` 或 `side` 无法修好，因为轮廓仍位于 Z=0。新版方案校验会在建模前拦截这类冲突。
2. 若是圆孔，确认它在所选面和切深范围内实际切到材料。报告中的 `circle_center_distance_to_selected_face_mm` 是圆心到所选实体面的距离。它大于圆半径时，圆在该面上没有材料可切；若后方截面会变化，还需检查切深范围。矩形管端面中央的空腔即使在包围盒里，也不是材料。
3. 若是闭合轮廓，先看方案中的折线是否自交、重叠或零面积。方案校验会在连接 SolidWorks 前拦截这些明显错误。插值样条仍可能在点间过冲，导致草图自交或超出实体。可在**新的方案副本**中仅对该操作设置 `"loop_mode": "polyline"`，保持轮廓点和切深不变，核对形状后再建模。折线会有棱角；如外形要求光顺，应由 Agent 重新拟合受控样条。
   1.2.3 起会自动删除轮廓中精确的 A、B、A 往返段，同时保留原始方案并记录删除数量。若 `Closed spline creation failed` 仍出现，检查该操作是否有更多重复点、尖角或拟合过冲。不要把所有轮廓直接改成折线并宣称形状一致。
4. 若轮廓和切深都合理，检查前面的特征是否把目标区域切掉、选面是否正确，以及相反面是否需要单独建模。只针对失败操作调整，再在新目录重建。不要在原失败目录覆盖模型和报告。

SolidWorks 2025 的实际版本主号为 33。版本匹配且已成功建出前面的特征，只能排除“连接到了错误主版本”这一种问题；不能证明失败由版本兼容性引起。没有原始方案与草图诊断时，应报告原因未确认。

## 长直线封口被拟合成弧线

一个 223 毫米长、约 1.4 毫米高的薄层轮廓，在输入点的最高位置为 25 毫米时，SolidWorks 生成的闭合样条可能鼓出到 53.6 毫米。输入多边形有效，实际样条也不一定自交，但生成形状已经偏离输入。不要把样条创建成功当作形状正确。

这种情况先对失败操作改用 `loop_mode=polyline`，保留点坐标、平面、切深和其他特征，再验证实体。若需要光顺边界，应分别建立起伏边界样条与直线封口，检查实际曲线偏差后再切除。不要对所有操作统一更换模式。
