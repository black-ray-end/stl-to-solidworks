# 建模与检查

## 看图顺序

先运行 `inspect_mesh.py` 看尺寸、闭合状态和坐标层级，再看总览确定长轴、空腔和安装端。只查看相关的相反两侧，必要时再看端面与指定截面。薄层和真实截面不是同一种资料，薄层可能遮住该层内部的孔，截面可能带有网格缺陷造成的杂线。

六方向按原始 XYZ 输出。每张图片的水平、竖直方向与二维原点记录在 JSON。二维点恢复为三维时，必须应用对应轴向和原点，不能把正反视图当成相同方向。

## 特征选择

- 规则外壳用拉伸或薄壁特征。壁厚用截面核对。
- 分段轴、法兰和固定截面的叉形结构先尝试 `build_axial.py`。由 Agent 从本次 STL 的 X 层级与截面制定方案，不能复制示例或以前零件的方案。
- 孔用圆和切除。圆拟合可以对轮廓顶点解圆方程，但要检查残差、圆弧覆盖率和两侧对应关系。不能将任意封闭洞都判为圆。
- 筋条切口用闭合样条。点数从少量开始，按误差增加，避免每个网格顶点都成为控制点。拟合后检查曲线自交和过冲。
- 两面优化形状不同就分别建模。对薄壁孔洞，切深为该侧实际壁厚，不能默认贯穿整个方管。
- 保留关键安装端和孔的尺寸。原始 CAD 可用于这些尺寸，但没有原 CAD 时不要假装尺寸来自设计图纸。
- 构造器不支持的弯管、放样、曲面、斜孔或多实体，由 Agent 自行写本次零件的建模脚本。脚本放在交付目录中，记录来源截面、拟合误差与简化位置，复用已验证的坐标和 COM 做法。

## 自动化细节

SolidWorks API 长度单位为米，项目/方案使用毫米。绘制二维草图之前，用 `ModelToSketchTransform` 将世界坐标转换到草图坐标。API 中拿到动态 COM 对象时，按生成的类型库包装 `IFace2`、`ISketch`、`IBody2` 等接口。

脚本优先使用对应年份的 `SldWorks.Application.<major>`，2024 对应 32。即使 ProgID 指定正确，也检查实际返回版本。模板优先应用自身默认模板，失效时只搜索同年份模板。可以用 `--template` 显式指定。

原生文件用 `OpenDoc6`；中性格式不能直接套用该方法。不要修改全局 STL 导出参数来满足某一个任务。实测导出 STL 可能平移到零原点或使用不同单位，比较前核对尺度和位置，不能未经说明自动缩放/旋转以获得好看的指标。

## 验证

默认只进行一轮必要验收。复用构造器的实体数、几何检查和目标版本重新打开结果。然后结合实际 CAD 数据或视图，一次核对关键尺寸、孔位与主要轮廓；内部形状不明确时补关键截面。结果追加到已有检查记录，检查通过后停止。

需要定量验收时才运行 `compare.py`，它报告粗略边界与体积，使用导出后的毫米 STL；如果导出单位有误会拒绝通过。没有实际异常或详细验收要求时，不自动增加多组截面、曲面偏差或反复投影计算。只有源 STL 闭合且绕向一致时，体积才有参考价值。

采用拟合而非精确还原时，记录最大允许偏差和改变的位置。对网格棱角光顺会改变形状，不默认为无损操作。
